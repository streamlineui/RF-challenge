# UI Challenge

## Running the Static Build Locally

To view the pre-built static application locally, ensure you have [Node.js](https://nodejs.org) installed, then follow these steps:

1. Navigate to the `build` directory:
   ```bash
   cd build
   ```

2. Start a local static server:
   ```bash
   npx serve
   ```

3. Open your browser and go to the local URL shown in your terminal (usually `http://localhost:3000`).
